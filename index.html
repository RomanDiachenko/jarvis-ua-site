Про застосунок

Jarvis UA — голосовий помічник у стилі J.A.R.V.I.S., що працює на комп'ютері користувача (Windows, macOS) і на телефоні Android. Він реагує на фразу «Привіт, Джарвіс», відкриває програми, ставить таймери й нагадування, читає погоду, новини та календар, допомагає з листами й керує розумним домом.

Більшість команд виконується локально. Для складних запитів використовується Claude API (Anthropic). Доступ до Google Календаря та Gmail потрібен, щоб асистент міг на вимогу користувача показати події, створити зустріч, прочитати листи чи підготувати чернетку відповіді.

Це особистий некомерційний проєкт для автора та невеликої кількості тестувальників.

About

Jarvis UA is a J.A.R.V.I.S.-style voice assistant that runs on the user's own computer (Windows, macOS) and Android phone. It wakes on a spoken phrase, opens programs, sets timers and reminders, reads the weather, news and calendar, helps with email and controls smart-home devices.

Most commands are handled locally on the device. Complex requests use the Claude API (Anthropic). Access to Google Calendar and Gmail lets the assistant, when the user asks, list events, create meetings, read emails or prepare a draft reply.

This is a personal, non-commercial project used by its author and a small number of testers.
