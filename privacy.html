Коротко

  • Jarvis UA працює на вашому пристрої. У розробника немає серверів, які збирають чи зберігають ваші дані.
  • Дані Google (Календар, Gmail, Google Home) використовуються лише для виконання ваших запитів. Вони не продаються, не передаються для реклами й не використовуються для навчання моделей ШІ.
  • Доступ можна будь-коли відкликати.

Які дані Google використовуються

  • Google Календар (calendar.events): перегляд, створення й видалення подій на ваш запит, нагадування про найближчі зустрічі.
  • Gmail (gmail.readonly, gmail.compose): читання листів на ваш запит, підрахунок непрочитаних, збереження вкладень і створення чернеток. Jarvis UA ніколи не надсилає листи сам.
  • Google Assistant API (необов'язково): передавання ваших команд пристроям розумного дому з застосунку Google Home.

Де зберігаються дані

Ключі доступу (OAuth-токени) зберігаються лише у файлах на вашому комп'ютері, у папці користувача Jarvis UA. Вміст листів і подій не зберігається, окрім короткочасного кешу для екрана HUD.

Кому передаються дані

  • Anthropic (Claude API): коли ви просите асистента щось зробити з листом чи подією, потрібний фрагмент (наприклад, текст листа чи назви подій) надсилається в Claude API, щоб сформулювати відповідь. Anthropic не використовує дані API для навчання моделей.
  • Microsoft (синтез мовлення Edge): текст відповідей асистента перетворюється на голос.
  • Telegram: лише якщо ви самі підключили свого Telegram-бота; тоді відповіді надходять вам у чат.

Розпізнавання голосу відбувається локально; аудіо з мікрофона нікуди не надсилається.

Обмежене використання

Використання й передавання інформації, отриманої з API Google, будь-якому іншому застосунку відповідає Політиці щодо даних користувачів сервісів Google API, зокрема вимогам щодо обмеженого використання (Limited Use).

Як видалити дані й відкликати доступ

  • У Jarvis UA: Налаштування → Підключення → Google → «Вийти» (токен видаляється з комп'ютера).
  • У акаунті Google: myaccount.google.com/permissions.
  • Видалення папки користувача Jarvis UA видаляє всі локальні дані асистента.

Контакти

Питання щодо конфіденційності: github.com/RomanDiachenko.

Summary

  • Jarvis UA runs on your own device. The developer operates no servers that collect or store your data.
  • Google user data (Calendar, Gmail, Google Home) is used only to carry out your requests. It is never sold, never used for advertising and never used to train AI models.
  • You can revoke access at any time.

Google data we access

  • Google Calendar (calendar.events): list, create and delete events when you ask, and remind you of upcoming meetings.
  • Gmail (gmail.readonly, gmail.compose): read emails when you ask, count unread messages, save attachments and create drafts. Jarvis UA never sends email on its own.
  • Google Assistant API (optional): pass your commands to smart-home devices from the Google Home app.

Storage

Access credentials (OAuth tokens) are stored only in files on your computer, in the Jarvis UA user folder. Email and event content is not stored, except for a short-lived cache for the HUD screen.

Sharing

  • Anthropic (Claude API): when you ask the assistant to do something with an email or event, the relevant part (for example the email text or event titles) is sent to the Claude API to compose the answer. Anthropic does not train models on API data.
  • Microsoft (Edge text-to-speech): the text of the assistant's replies is turned into speech.
  • Telegram: only if you connect your own Telegram bot; replies are then delivered to your chat.

Speech recognition runs locally; microphone audio is not sent anywhere.

Limited Use

Jarvis UA's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

  • In Jarvis UA: Settings → Connections → Google → "Sign out" (the token is deleted from your computer).
  • In your Google Account: myaccount.google.com/permissions.
  • Deleting the Jarvis UA user folder removes all of the assistant's local data.
